# Theodore

🇬🇧 **English**

19.

I don't really know what I'm doing here.

I just keep opening doors that probably weren't meant to be opened.

Sometimes I disappear for a while.

Sometimes I come back with something broken.

Anyway, you're already here.

**Don't look too far.**

🇷🇺 **Русский**

19.

Я сам не особо понимаю, что я здесь делаю.

Просто продолжаю открывать двери, которые, наверное, не стоило открывать.

Иногда я надолго исчезаю.

Иногда возвращаюсь с чем-нибудь сломанным.

В любом случае, ты уже здесь.

**Не заглядывай слишком далеко.**
